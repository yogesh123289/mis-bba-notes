# 2. Introduction

In the previous topic, we started our journey from:

> **Data → Data Storage → Files → File Management System**

A file management system can store and manage data.

But as organizations become larger, the amount of data also increases.

For example, a university may have data related to:

- Students
- Faculty
- Courses
- Admissions
- Fees
- Attendance
- Examinations
- Library
- Hostel
- Transport
- Placements

If every department stores its information separately in different files, managing all this data becomes difficult.

Therefore, organizations needed a better method of managing data.

This led to the development of the:

> **Database Approach**

---

# 3. From File System to Database Approach

Let us understand the evolution.

```text
DATA
  ↓
DATA STORAGE
  ↓
FILES
  ↓
FILE PROCESSING SYSTEM
  ↓
PROBLEMS WITH FILE SYSTEM
  ↓
DATABASE APPROACH
  ↓
DATABASE
  ↓
DBMS
```
The important question is:

Why did organizations move from traditional files to databases?

The answer is:

Because traditional file systems created several problems when the volume, complexity and number of users increased.
