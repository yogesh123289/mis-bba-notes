## Introduction to Data, Data Storage and Databases

---

## 1. Introduction

Every organization generates and uses a large amount of data every day.

For example, a university generates data about:

- Students
- Faculty
- Courses
- Attendance
- Marks
- Fees
- Examinations
- Library
- Admissions

Similarly, a business generates data about:

- Customers
- Products
- Sales
- Employees
- Suppliers
- Payments
- Inventory

The important question is:

> **Where do organizations store all this data, and how do they manage it?**

To understand the need for a **Database Management System (DBMS)**, we should first understand the journey of data:

```text
Data
  ↓
Data Storage
  ↓
Files
  ↓
File Management System
  ↓
Problems of File Management
  ↓
Database Approach
  ↓
Database
  ↓
DBMS
```
